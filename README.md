# another-green-world
Another Green World is a Last.FM Music Recommendation Engine/Agent

**Another Green World** is a Last.FM Music Recommendation Engine and Autonomous Agent.

The goal of a project is to learn Machine Learning(ML) and building autonomous AI agents and also to expand my knowledge into Python's Django framework and pandas, numpy.

The name of the project is based on Brian Eno's album, which is one of my favourite albums ever,
however it took me too many years to discover it, perhaps if I used a tool like I would have discovered it earlier!

## Tech stack

- **Backend:** Python, Django
- **ML:** pandas, numpy
- **Development:** Docker
- **Data:** Last.FM API
- **Tools:** NeoVim

## Project status

Another Green World is under active development.
